## 按照交互原型修复应用计划

### 问题分析
1. **UI设计不符合交互原型**：当前应用的UI设计与交互原型不符，包括布局、颜色、组件样式等
2. **登录注册流程不同**：原型使用标签页切换登录和注册，当前应用使用密码/验证码登录切换
3. **验证码功能不完整**：当前应用只有模拟倒计时，没有实际的验证码发送和验证功能
4. **缺少部分功能**：缺少体验APP、忘记密码等功能

### 修复方案

1. **重新设计登录注册界面**
   - 按照交互原型实现渐变背景和特定颜色方案
   - 实现登录/注册标签页切换
   - 调整表单字段，登录表单只保留手机号和验证码
   - 添加忘记密码、体验APP等功能
   - 添加用户协议和隐私政策链接

2. **实现完整的验证码功能**
   - 在 `UserContext` 中添加 `sendVerificationCode` 函数
   - 实现验证码存储和验证逻辑
   - 完善登录和注册流程

3. **更新登录注册流程**
   - 登录流程：手机号 + 验证码
   - 注册流程：手机号 + 验证码 + 设置密码
   - 添加体验APP功能，允许用户无需登录即可体验

4. **按照原型实现其他页面**
   - 实现AI诊断模式选择页面
   - 实现AI聊天诊断页面
   - 实现AI兽医诊断页面
   - 实现诊断报告页面

### 修复步骤

1. **修改 LoginScreen.tsx**
   - 按照交互原型重新设计登录注册界面
   - 实现登录/注册标签页切换
   - 调整表单字段，登录表单只保留手机号和验证码
   - 添加忘记密码、体验APP等功能
   - 添加用户协议和隐私政策链接

2. **修改 UserContext.tsx**
   - 添加 `sendVerificationCode` 函数
   - 扩展 `login` 函数，支持验证码登录
   - 添加 `register` 函数，支持手机号+验证码+密码注册

3. **更新 AuthContextType**
   - 添加 `sendVerificationCode` 和 `register` 函数类型定义
   - 更新 `login` 函数类型定义

4. **实现体验APP功能**
   - 在导航流程中添加体验模式选项
   - 允许用户无需登录即可进入应用体验

5. **按照原型实现其他页面**
   - 实现AI诊断模式选择页面
   - 实现AI聊天诊断页面
   - 实现AI兽医诊断页面
   - 实现诊断报告页面

### 预期结果
- 应用UI设计完全按照交互原型实现
- 支持手机号+验证码登录和手机号+验证码+密码注册
