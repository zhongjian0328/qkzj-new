# 禽康智检APP系统部署计划

## 1. 部署前准备

### 1.1 版本确认
- 确认当前代码版本：e90c546 (HEAD -> master) Initial commit: 完成项目第一阶段（启动阶段）工作
- 核对版本号与发布记录一致
- 确保部署包为最新版本

### 1.2 环境准备
- 云服务器：Ubuntu 22.04 LTS，2核4G内存，50GB SSD存储
- 云数据库：MongoDB 8.2.2，1核2G内存，100GB存储
- CDN/负载均衡：配置HTTPS证书和域名解析

## 2. 部署步骤

### 2.1 前端部署
1. **拉取代码**：`git clone https://github.com/your-repo/qinkangzhijian.git && cd qinkangzhijian`
2. **安装依赖**：`npm install`
3. **配置环境变量**：创建`.env.production`文件并配置生产环境变量
4. **构建应用**：`npm run build:web`
5. **部署到服务器**：使用Nginx配置静态文件服务和HTTPS

### 2.2 后端部署
1. **拉取代码**：`git clone https://github.com/your-repo/qinkangzhijian-backend.git && cd qinkangzhijian-backend`
2. **安装依赖**：`npm install`
3. **配置环境变量**：创建`.env`文件并配置生产环境变量
4. **启动服务**：使用PM2管理进程，配置开机自启
5. **配置Nginx反向代理**：配置HTTPS和API路由

### 2.3 数据库部署
1. **创建MongoDB实例**：使用云数据库服务或自行部署
2. **配置数据库**：创建数据库`qinkangzhijian`，创建用户并授权，配置IP白名单
3. **初始化数据**：从备份导入初始数据（如适用）

## 3. 部署验证

### 3.1 功能验证
- 前端功能验证：页面加载、用户登录注册、AI诊断、生产管理等
- 后端API验证：健康检查、认证API、AI诊断API、生产管理API等

### 3.2 性能验证
- 负载测试：使用JMeter或LoadRunner验证高并发下的性能
- 响应时间测试：测试API响应时间和页面加载时间

### 3.3 日志检查
- 检查前端控制台日志，确保无错误
- 检查后端应用日志，确保无错误
- 检查数据库日志，确保无异常

## 4. 监控机制

### 4.1 应用监控
- 使用PM2监控后端进程
- 配置Prometheus + Grafana监控系统指标

### 4.2 日志管理
- 配置Winston或Bunyan记录日志
- 配置日志轮转和定期备份

### 4.3 24小时观察
- 持续观察系统运行状态24小时
- 检查系统无异常中断或性能下降
- 确保响应时间符合要求

## 5. 回滚方案

- 前端回滚：从备份恢复静态文件
- 后端回滚：使用PM2回滚到上一版本
- 数据库回滚：从最新备份恢复数据

## 6. 应急方案

- 服务器故障：切换到备用服务器
- 数据库故障：切换到备用数据库
- 安全漏洞：采取临时措施缓解漏洞，紧急修复并部署

## 7. 部署完成标准

1. 系统各模块正常运行
2. 响应时间符合要求
3. 无错误日志产生
4. 监控机制正常工作
5. 系统稳定运行24小时无异常
