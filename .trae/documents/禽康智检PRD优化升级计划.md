## 3. 技术栈明确

### 3.1 前端技术栈
- **框架**: React Native (跨平台开发)
- **UI库**: Tailwind CSS (样式设计)
- **状态管理**: Redux Toolkit
- **网络请求**: Axios
- **图像处理**: React Native Image Picker, react-native-camera
- **地图服务**: 高德地图/百度地图SDK

### 3.2 后端技术栈
- **语言**: Node.js
- **框架**: Express.js/Koa.js
- **数据库**: 
  - 关系型数据库: MySQL/PostgreSQL (用户数据、生产数据、订单数据)
  - 非关系型数据库: MongoDB (诊断记录、实习日志)
  - 对象存储: OSS/S3 (图片、视频存储)
- **AI服务**: 百度云图像识别API, DeepSeek API
- **认证授权**: JWT
- **缓存**: Redis

### 3.3 开发环境
- **开发工具**: VS Code, Android Studio, Xcode
- **版本控制**: Git/GitHub
- **CI/CD**: GitHub Actions/Jenkins
- **测试工具**: Jest, React Testing Library, Postman

### 3.4 生产环境
- **服务器**: 云服务器 (阿里云/腾讯云)
- **容器化**: Docker
- **部署**: Kubernetes
- **监控**: Prometheus, Grafana
- **日志**: ELK Stack
