# 修复不同角色显示相同首页的问题

## 问题分析
1. **App.tsx**：主标签导航的所有标签页都使用了`HomeScreen`组件，包括"我的"标签页
2. **ExperienceRoleScreen.tsx**：选择体验角色后，没有将角色信息传递给`AuthProvider`
3. **UserContext.tsx**：`login`函数硬编码了用户角色为`FARMER`
4. **HomeScreen.tsx**：虽然有角色判断逻辑，但由于用户角色始终是`FARMER`，所以所有用户看到的都是相同的界面

## 修复方案

### 1. 修复App.tsx
- 创建独立的ProfileScreen组件，替换"我的"标签页的HomeScreen组件

### 2. 修复ExperienceRoleScreen.tsx
- 修改`handleStartExperience`函数，将选择的角色信息传递给`AuthProvider`
- 添加角色映射逻辑，将体验角色ID映射为对应的UserRole和UserSubRole

### 3. 修复UserContext.tsx
- 修改`login`函数，移除硬编码的角色信息
- 添加支持通过体验角色登录的功能

### 4. 添加角色映射工具函数
- 创建一个工具函数，将体验角色ID映射为对应的UserRole和UserSubRole

## 修复步骤

1. **创建ProfileScreen.tsx**：
   - 创建新的个人中心页面组件
   - 实现用户信息展示和设置功能

2. **修改App.tsx**：
   - 导入ProfileScreen组件
   - 在主标签导航中使用ProfileScreen替换"我的"标签页的HomeScreen

3. **修改ExperienceRoleScreen.tsx**：
   - 添加角色映射逻辑
   - 修改`handleStartExperience`函数，将角色信息传递给`AuthProvider`

4. **修改UserContext.tsx**：
   - 扩展`login`函数，支持通过体验角色登录
   - 修改`mockUser`生成逻辑，根据传入的角色信息生成不同的用户

5. **修改RoleSelectScreen.tsx**（如果需要）：
   - 确保注册流程中选择的角色能正确保存到用户信息中

## 预期效果
- 用户选择不同的体验角色后，首页会显示对应的功能模块
- 养殖户、机构和学生看到不同的功能区域
- 个人中心页面显示正确的用户信息和角色相关功能

- 测试登录后角色信息是否正确保存
- 测试不同角色的功能模块是否正确显示
- 测试个人中心页面是否正确显示用户信息
