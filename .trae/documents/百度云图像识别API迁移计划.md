# 百度云图像识别API迁移计划

## 一、迁移目标
将项目中所有AI能力模块统一迁移到百度云图像识别API，实现安全、高效、稳定的AI服务调用。

## 二、现有AI服务分析

### 1. 现有AI功能模块
- 百度云动物识别
- 百度云图像分析
- DeepSeek API对话功能（诊断、风险评估、紧急方案、治疗调整、养殖建议、疾病预警）
- 阿里云NLP智能诊断引擎

### 2. 迁移范围
- 替换所有非百度云AI服务为百度云图像识别API
- 集成加密文件实现安全调用
- 优化现有百度云API调用，统一使用组合接口

## 三、迁移实施计划

### 1. 模块拆分与设计

| 模块名称 | 现有实现 | 迁移后实现 |
|---------|---------|-----------|
| 图像识别基础服务 | 百度云独立接口 | 百度云组合接口，支持多场景识别 |
| 智能诊断服务 | DeepSeek/阿里云NLP | 基于百度云图像识别结果的智能诊断（需结合百度云其他AI服务） |
| 风险评估服务 | DeepSeek API | 基于百度云图像识别结果的风险评估 |
| 紧急控制方案 | DeepSeek API | 基于百度云图像识别结果的紧急方案生成 |
| 治疗调整建议 | DeepSeek API | 基于百度云图像识别结果的治疗调整建议 |
| 养殖建议生成 | DeepSeek API | 基于百度云图像识别结果的养殖建议 |
| 疾病风险预警 | DeepSeek API | 基于百度云图像识别结果的疾病预警 |
| 安全加密模块 | 无 | 集成加密文件实现安全API调用 |

### 2. 接口对接方案

#### 2.1 百度云API认证机制
- 保留现有`getBaiduAccessToken()`方法
- 集成加密文件解密逻辑，安全存储API密钥

#### 2.2 组合接口调用设计
```javascript
async callBaiduCombinationAPI(imageBuffer, scenes, sceneConf = {}) {
  const accessToken = await this.getBaiduAccessToken();
  const imageBase64 = imageBuffer.toString('base64');
  
  const response = await axios.post(
    'https://aip.baidubce.com/api/v1/solution/direct/imagerecognition/combination',
    {
      image: imageBase64,
      scenes: scenes,
      sceneConf: sceneConf
    },
    {
      params: { access_token: accessToken },
      headers: { 'Content-Type': 'application/json' }
    }
  );
  
  return response.data;
}
```

#### 2.3 现有方法迁移
- `recognizeAnimal()` → 调用组合接口，scenes: ['animal']
- `analyzeImage()` → 调用组合接口，scenes: ['advanced_general']
- 其他基于文本的AI功能 → 需结合百度云其他AI服务（如自然语言处理API）

### 3. 数据流转设计

1. **图像输入** → 2. **加密处理** → 3. **百度云API调用** → 4. **结果解析** → 5. **业务逻辑处理** → 6. **结果返回**

### 4. 错误处理机制

| 错误类型 | 处理方式 |
|---------|---------|
| API调用失败 | 重试机制（最多3次） |
| 认证失败 | 重新获取AccessToken |
| 图像格式错误 | 返回友好错误信息 |
| 服务不可用 | 降级处理，返回默认结果 |

## 四、加密文件集成方案

1. **加密文件解析**：实现二进制文件解密逻辑
2. **安全存储**：解密后的API密钥安全存储在内存中
3. **密钥管理**：定期轮换密钥，确保安全性

## 八、优化建议

1. **添加缓存机制**：缓存API调用结果，减少重复请求
2. **异步处理**：对于耗时较长的AI任务，实现异步处理
3. **监控告警**：添加API调用监控，及时发现并处理问题
4. **日志记录**：完善日志记录，便于问题排查和分析
