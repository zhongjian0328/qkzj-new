# 构建开发预览版环境计划

## 1. 环境概述

本计划旨在构建一个完整的开发预览版环境，包含前端和后端的最新开发代码，支持实时代码更新和热重载功能，确保预览环境能够准确反映开发分支的最新状态。

## 2. 技术栈

- **前端**: React Native + Expo
- **后端**: Express + Node.js
- **数据库**: MongoDB

## 3. 构建步骤

### 3.1 前端开发服务器配置

1. **启动前端开发服务器**
   - 命令: `npm start` (在项目根目录执行)
   - 支持平台: Android、iOS、Web
   - 热重载: 内置支持，代码修改后自动更新
   - 访问方式: 
     - Expo Go 应用扫描二维码
     - Web 浏览器访问 `http://localhost:8081`

2. **配置热重载**
   - Expo 开发服务器默认支持热重载
   - 确保 `metro.config.js` 配置正确，支持实时更新

### 3.2 后端开发服务器配置

1. **启动后端开发服务器**
   - 命令: `npm start` (在 `backend` 目录执行)
   - 端口: 默认 3000
   - 访问方式: `http://localhost:3000`

2. **配置热重载**
   - 安装 `nodemon` 依赖: `npm install -D nodemon`
   - 修改 `package.json` 脚本: 
     ```json
     "scripts": {
       "start": "nodemon index.js"
     }
     ```
   - 支持代码修改后自动重启服务器

### 3.3 前后端联动配置

1. **前端API配置**
   - 确保 `src/services/api.ts` 中的 `baseURL` 指向后端开发服务器
   - 配置: `baseURL: process.env.EXPO_PUBLIC_API_URL || 'http://localhost:3000/api'`

2. **跨域配置**
   - 后端已配置 CORS 中间件，支持前端跨域访问
   - 配置: `app.use(cors())`

### 3.4 数据库配置

1. **MongoDB连接**
   - 确保 `.env` 文件中配置了正确的 MongoDB 连接字符串
   - 配置: `MONGODB_URI=mongodb://localhost:27017/qinkangzhijian`

2. **数据库初始化**
   - 确保数据库服务已启动
   - 后端启动时自动连接数据库

## 4. 访问方式

### 4.1 本地访问

- **前端**: 
  - Expo Go: 扫描终端显示的二维码
  - Web: `http://localhost:8081`
- **后端**: `http://localhost:3000`
- **API健康检查**: `http://localhost:3000/api/health`

### 4.2 远程访问 (可选)

- 使用 `ngrok` 或类似工具暴露本地端口
- 配置: `ngrok http 8081` (前端) 和 `ngrok http 3000` (后端)
- 生成临时公网URL，用于远程预览

## 5. 环境监控

1. **后端日志**
   - 使用 `morgan` 中间件记录HTTP请求
   - 日志输出到终端

2. **前端调试**
   - 使用 Chrome DevTools 或 Expo DevTools 进行调试
   - 支持实时日志查看和断点调试

## 6. 注意事项

1. **依赖安装**
   - 确保前端和后端的依赖都已正确安装
   - 前端: `npm install` (根目录)
   - 后端: `npm install` (backend目录)

2. **环境变量**
   - 确保 `.env` 文件配置正确
   - 包含必要的API密钥和数据库连接信息

3. **端口占用**
   - 确保端口 8081 (前端) 和 3000 (后端) 未被占用
   - 如需修改端口，更新相应配置文件

4. **热重载限制**
   - 某些配置文件修改可能需要重启服务器
   - 原生模块修改需要重新构建应用

## 7. 验证步骤

1. **启动前端和后端服务器**
2. 修改前端代码，检查是否自动更新
3. 修改后端代码，检查是否自动重启
4. 访问API端点，验证前后端连接正常
5. 测试核心功能，确保正常工作
