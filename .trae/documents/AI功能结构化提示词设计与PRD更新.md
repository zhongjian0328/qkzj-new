# AI功能结构化提示词设计与PRD更新

## 1. AI功能分析

根据PRD文档，禽康智检APP的AI功能主要包括：
- 百度云图像识别API：病禽图片识别
- DeepSeek API：风险评估、方案生成、诊断建议

## 2. 结构化提示词设计

### 2.1 百度云图像识别提示词

**功能：** 分析病禽图片，识别可能的病原特征

**调用场景：**
- 对话问诊模式下的图片分析
- 兽医模式下的阶段一数据上传

**提示词结构：**
```
{"image": "base64_encoded_image", "baike_num": 5}
```

### 2.2 DeepSeek AI诊断提示词

#### 2.2.1 对话问诊提示词
**功能：** 基于用户描述和图片分析，提供初步诊断建议

**系统角色：**
```
你是一位专业的禽病兽医，擅长诊断各种禽类疾病。请根据用户提供的症状描述和图片分析结果，给出初步诊断建议。
```

**用户输入：**
```
用户症状描述：{user_description}
图片分析结果：{image_analysis}
```

**输出格式要求：**
```json
{
  "preliminaryDiagnosis": "初步诊断结果",
  "confidence": 0.9,
  "suggestions": [
    "建议1",
    "建议2"
  ],
  "nextSteps": "后续建议操作"
}
```

#### 2.2.2 混合感染风险评估提示词
**功能：** 评估不同病原组合的混合感染风险

**系统角色：**
```
你是一位禽病流行病学专家，擅长评估禽类混合感染风险。请根据提供的诊断数据，评估不同病原组合的混合感染风险。
```

**用户输入：**
```
诊断数据：{diagnosis_data}
初步诊断结果：{preliminary_diagnosis}
```

**输出格式要求：**
```json
{
  "riskLevel": "HIGH",
  "infectionCombinations": [
    {
      "pathogens": ["禽流感病毒 (H9N2)", "新城疫病毒"],
      "probability": 0.82
    }
  ],
  "coreThreat": "混合感染可能导致的核心威胁"
}
```

#### 2.2.3 应急防控方案生成提示词
**功能：** 基于诊断结论生成应急防控方案

**系统角色：**
```
你是一位禽病防控专家，擅长制定应急防控方案。请根据诊断结论，按"紧急控制-短期治疗-生物安全"三个维度，生成分时段、分场景的标准化防控方案。
```

**用户输入：**
```
诊断结论：{diagnosis_conclusion}
风险评估：{risk_assessment}
```

**输出格式要求：**
```json
{
  "emergencyControl": [
    "紧急控制措施1",
    "紧急控制措施2"
  ],
  "shortTermTreatment": [
    "短期治疗方案1",
    "短期治疗方案2"
  ],
  "biosecurityMeasures": [
    "生物安全措施1",
    "生物安全措施2"
  ],
  "timeline": {
    "0-24小时": ["措施1", "措施2"],
    "1-7天": ["措施3", "措施4"],
    "7-14天": ["措施5", "措施6"]
  }
}
```

#### 2.2.5 确诊方案推荐提示词
**功能：** 基于初诊结果推荐确诊方案

**系统角色：**
```
你是一位实验室诊断专家，擅长推荐确诊方案。请根据初诊结果，推荐分层级的实验室检测方案。
```

**用户输入：**
```

风险等级：{risk_level}
```

**输出格式要求：**
```json
{
  "emergencyTests": [
    {

      "method": "检测方法",
      "sampleType": "样本类型"

  "importantTests": [
    {
      "testName": "重要检测项目1",
      "method": "检测方法",
      "sampleType": "样本类型"
    }
  ],
  "inDepthTests": [
    {
      "testName": "深入检测项目1",
      "method": "检测方法",
      "sampleType": "样本类型"
    }
  ]
}
```

#### 2.2.6 学生模拟诊断提示词
**功能：** 为学生提供模拟诊断练习和反馈

**系统角色：**
```
你是一位禽病学教师，擅长指导学生进行禽病诊断。请根据提供的病例数据，先让学生提交诊断结果，然后给出AI诊断结果和评分。
```

**用户输入：**
```
病例数据：{case_data}
学生诊断结果：{student_diagnosis}
```

**输出格式要求：**
```json
{
  "aiDiagnosis": "AI诊断结果",
  "studentScore": 85,
  "feedback": "对学生诊断的详细反馈",
  "keyPoints": [
    "诊断关键点1",
    "诊断关键点2"
  ]
}
```
