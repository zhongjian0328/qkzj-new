# 禽康智检APP开发计划

## 1. 开发阶段划分

### 1.1 前端开发计划

#### 1.1.1 核心组件开发
- 开发基础UI组件：按钮、卡片、输入框、标签页、导航栏等
- 实现统一的样式系统，基于Tailwind CSS
- 开发状态管理Context，用于管理用户信息、主题、语言等全局状态

#### 1.1.2 页面开发
- 登录/注册页面（P-LOGIN_REGISTER）
- 角色选择页面（P-ROLE_SELECT）
- 认证页面（P-AUTH_CERTIFICATION）
- 各角色首页（P-HOME_*）
- AI诊断模式选择页面（P-AI_DIAGNOSIS_MODE_SELECT）
- 对话问诊模式页面（P-AI_DIAGNOSIS_CHAT）
- AI兽医模式页面（P-AI_DIAGNOSIS_VET）
- 诊断报告页面（P-AI_PRE_DIAGNOSIS_REPORT、P-AI_FINAL_DIAGNOSIS_REPORT）

#### 1.1.3 API集成
- 集成前端API服务，确保所有页面能正确调用后端API
- 实现错误处理和加载状态管理
- 开发API请求封装，支持取消请求、重试机制等

### 1.2 后端开发计划

#### 1.2.1 数据模型设计
- 用户模型（Users）
- 组织机构模型（Organizations）
- 诊断记录模型（Diagnosis_Records）
- 养殖批次模型（Breeding_Batches）
- 生产数据模型（Production_Data）
- 实习日志模型（Internship_Logs）
- 知识图谱模型（Knowledge_Graph）
- 题库模型（Question_Bank）
- 订单模型（Orders）

#### 1.2.2 控制器开发
- 用户认证控制器：处理注册、登录、验证码发送等
- AI诊断控制器：处理对话问诊、兽医模式诊断、报告生成等
- 生产管理控制器：处理批次管理、死淘/耗料记录等
- 疫情监测控制器：处理疫情热力图数据、异常报警等
- 实习管理控制器：处理实习日志、导师批注等
- 知识学习控制器：处理图谱百科、题库测验等
- 商业服务控制器：处理商品管理、订单创建等
- 科研协作控制器：处理病例标注、群组管理等

#### 1.2.3 路由配置
- 实现RESTful API路由，对应前端API服务中的所有请求
- 配置路由中间件，处理认证、权限检查等

#### 1.2.4 AI服务集成
- 集成百度云图像识别API，处理病禽图片识别
- 集成DeepSeek API，处理风险评估、方案生成等
- 实现AI诊断逻辑，包括单病原识别、混合感染风险评估等

### 1.3 数据库设计

#### 1.3.1 集合结构设计
- 设计合理的集合结构，确保数据存储高效
- 实现适当的索引，提高查询性能
- 设计数据关系，确保数据一致性

#### 1.3.2 数据迁移
- 实现数据迁移脚本，便于数据库结构更新
- 设计初始数据，用于测试和演示

### 1.4 测试计划

#### 1.4.1 单元测试
- 为前端组件和工具函数编写单元测试
- 为后端控制器和模型编写单元测试
- 使用Jest和React Testing Library进行测试

#### 1.4.2 集成测试
- 测试API端点，确保它们能正确处理请求和响应
- 测试前后端集成，确保页面能正确调用API
- 测试AI服务集成，确保AI诊断功能正常工作

#### 1.4.3 端到端测试
- 使用Expo Go在真机上测试应用功能
- 测试不同角色的权限和功能访问
- 测试应用的性能和稳定性

### 1.5 部署计划

#### 1.5.1 本地部署
- 配置本地开发环境，包括MongoDB、Node.js、Expo等
- 实现本地开发服务器，支持热更新

#### 1.5.2 测试环境部署
- 配置测试服务器，部署后端服务和数据库
- 构建测试版本的前端应用，用于测试

#### 1.5.3 生产环境部署
- 配置生产服务器，确保高可用性和安全性
- 实现CI/CD流程，自动化构建和部署
- 配置监控和日志系统，便于问题排查

## 3. 技术规范

### 3.1 代码规范
- 前端使用TypeScript，遵循ESLint和Prettier规范
- 后端使用JavaScript，遵循ESLint规范
- 代码注释清晰，便于维护和理解
- 采用模块化设计，提高代码复用性和可维护性

### 3.2 命名规范
- 变量和函数名使用驼峰式命名
- 组件和页面名使用帕斯卡式命名
- 常量使用大写字母和下划线分隔
- 文件和目录名使用小写字母和连字符分隔

### 3.3 安全规范
- 所有敏感数据加密存储和传输
- 实现JWT认证，确保API安全
- 防止SQL注入、XSS攻击等常见安全漏洞
- 保护AI服务API密钥，实现API调用频率限制
