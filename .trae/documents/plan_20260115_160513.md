# 终端错误问题修复方案

## 1. 问题识别

### 1.1 图标警告问题

* **错误类型**: 图标名称无效

* **错误信息**: "hospital-outline" is not a valid icon name for family "ionicons"

* **触发原因**: Ionicons图标库中不存在该图标名称

* **影响范围**: UI显示异常

### 1.2 网络连接失败问题

* **错误类型**: 网络连接错误

* **错误信息**: 网络连接失败，请检查您的网络设置；聊天诊断失败: \[AxiosError: Network Error]

* **触发原因**: 前端无法连接到后端服务或后端无法连接到外部AI服务

* **影响范围**: 所有需要网络连接的功能，特别是AI诊断功能

## 2. 修复方案

### 2.1 图标警告修复

1. **定位问题文件**: src/screens/HomeScreen.tsx:46
2. **替换无效图标**: 将"hospital-outline"替换为Ionicons库中存在的有效图标
3. **建议替代图标**: "medical-outline"或"stethoscope-outline"
4. **操作步骤**:

   * 打开HomeScreen.tsx文件

   * 找到第46行的icon配置

   * 将'hospital-outline'替换为'medical-outline'

### 2.2 网络连接失败修复

1. **检查后端服务状态**: 确保后端服务正在运行在<http://localhost:3000>
2. **验证前端API配置**: 检查baseURL是否正确指向后端服务
3. **添加网络状态检测**: 在API服务中添加网络连接状态检测
4. **实现重试机制**: 对网络请求添加重试逻辑
5. **操作步骤**:

   * 确保后端服务正常运行

   * 检查API配置文件中的baseURL

   * 添加网络连接状态检测函数

   * 为API请求添加重试机制

### 3.2 网络连接修复

1. **添加网络状态检测**:

   ```typescript
   // 在src/services/api.ts中添加
   const checkNetworkStatus = async () => {
     try {
       await api.get('/health');
       return true;
     } catch (error) {
       return false;
     }
   };
   ```

2. **为API请求添加重试机制**:

   ```typescript
   // 修改axios实例配置，添加重试逻辑
   const api = axios.create({
     baseURL: process.env.EXPO_PUBLIC_API_URL || 'http://localhost:3000/api',
     timeout: 65000,
     headers: {
       'Content-Type': 'application/json',
     },
     retry: 3,
     retryDelay: (retryCount) => Math.pow(2, retryCount) * 1000,
   });
   ```
