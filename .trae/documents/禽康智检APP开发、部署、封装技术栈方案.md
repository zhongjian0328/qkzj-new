# 禽康智检APP开发、部署、封装技术栈方案

## 一、技术栈选型

### 1. 前端技术栈
- **框架**: React Native (Expo SDK 54.0.18)
- **语言**: JavaScript/TypeScript
- **UI组件库**: React Native Paper + Tailwind CSS (或Expo内置组件)
- **状态管理**: React Context API + useReducer (或Redux Toolkit)
- **API请求**: Axios
- **导航**: React Navigation
- **身份认证**: JWT

### 2. 后端技术栈
- **框架**: Express 5.2.1 (已安装)
- **语言**: JavaScript
- **数据库**: MongoDB 8.2.2 (已安装)
- **ODM**: Mongoose 9.0.1 (已安装)
- **身份认证**: JWT (已安装)
- **密码加密**: bcrypt (已安装)
- **跨域支持**: CORS (已安装)
- **环境变量**: dotenv (已安装)
- **日志**: morgan (已安装)

### 3. 开发与部署工具
- **开发环境**: Windows 11 Pro 25H2
- **IDE**: VS Code + Trae
- **版本控制**: Git 2.52.0 (已安装)
- **包管理**: npm (Node.js v24.11.1 已安装)
- **APP构建**: Expo 54.0.18 (已安装)

## 二、项目架构

### 1. 前端架构
```
frontend/
├── app/                  # Expo app目录
│   ├── (tabs)/           # 标签页导航
│   ├── _layout.tsx        # 根布局
│   └── [screen]/         # 各功能页面
├── components/           # 可复用组件
├── contexts/             # React Context
├── hooks/                # 自定义hooks
├── services/             # API服务
├── utils/                # 工具函数
└── types/                # TypeScript类型定义
```

### 2. 后端架构
```
backend/
├── config/              # 配置文件
├── controllers/         # API控制器
├── middleware/          # 中间件
├── models/              # 数据库模型
├── routes/              # API路由
├── utils/               # 工具函数
├── index.js            # 应用入口
└── package.json        # 依赖配置
```

### 3. 数据库架构
- **用户表**: users
- **诊断记录表**: diagnosis_records
- **报告表**: reports
- **疫情数据表**: epidemic_data
- **学习资源表**: learning_resources
- **实习记录表**: intern_logs
- **消息表**: messages
