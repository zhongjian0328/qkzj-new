## 交互原型设计系统一致性修订

### 任务目标
根据PRD文档中的设计系统与一致性要求，对所有交互原型页面进行全面检查和修订，确保所有页面的设计风格统一，符合PRD规范。

### 主要问题
1. **颜色规范不一致**：
   - 部分页面使用旧颜色值：`primary: '#D3F8EE', secondary: '#3BCCA5', accent: '#2B6A5A'`
   - 部分页面使用新颜色值：`primary: '#E6F7F3', secondary: '#2DBBA1', accent: '#1F5E52'`
   - 部分页面颜色定义不完整（缺少success、warning等状态色）

2. **设计系统执行不统一**：组件样式、布局规范等执行不一致

### 修订范围
所有交互原型页面（UI_GENERATION目录下的所有HTML文件）

### 修订内容

#### 1. 统一颜色规范
将所有页面的颜色定义统一为PRD文档中规定的颜色值：
```javascript
colors: {
    primary: '#E6F7F3',
    secondary: '#2DBBA1',
    accent: '#1F5E52',
    'text-primary': '#111827',
    'text-secondary': '#4B5563',
    'text-tertiary': '#9CA3AF',
    'bg-light': '#F3F4F6',
    'card-bg': '#FFFFFF',
    'border-color': '#E5E7EB',
    'success': '#10B981',
    'warning': '#F59E0B',
    'error': '#EF4444',
    'info': '#3B82F6'
}
```

#### 2. 统一渐变背景
```css
.gradient-bg {
    background: linear-gradient(135deg, #E6F7F3 0%, #2DBBA1 100%);
}
```

#### 3. 统一组件样式
确保所有组件（卡片、按钮、输入框等）遵循PRD中的组件规范：
- 卡片：圆角12px，阴影0 2px 8px rgba(0, 0, 0, 0.06)，内边距16px
- 按钮：圆角8px，阴影0 2px 4px rgba(45, 187, 161, 0.2)，内边距12px 24px
- 输入框：圆角8px，边框1px solid #E5E7EB，内边距12px

#### 4. 统一布局规范
- 顶部导航栏：高度56px，背景色white，阴影0 2px 4px rgba(0, 0, 0, 0.05)
- 底部导航栏：高度64px，背景色white，阴影0 -2px 4px rgba(0, 0, 0, 0.05)
- 主要内容区域：内边距16px

### 修订步骤

1. **检查所有页面**：遍历UI_GENERATION目录下的所有HTML文件
2. **提取需要修订的页面列表**：找出颜色规范与PRD不一致的页面
3. **批量修订颜色规范**：
   - 替换旧颜色值为PRD规定的新颜色值
   - 补充完整的颜色定义
   - 统一渐变背景样式
4. **检查组件样式**：确保所有组件遵循PRD规范
5. **检查布局规范**：确保所有页面布局符合PRD要求
6. **测试页面效果**：确保修订后的页面样式统一、视觉效果良好

### 预期效果
- 所有交互原型页面使用统一的颜色规范
- 所有页面的设计风格一致
- 符合PRD文档中的设计系统与一致性要求
- 提高原型的专业性和可信度

### 优先级
1. 首先修订颜色规范（最明显的不一致问题）
2. 其次修订组件样式和布局规范
3. 最后进行全面测试和优化
